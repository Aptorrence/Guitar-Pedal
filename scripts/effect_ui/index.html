Effect Chain Tester

Pick a 16-bit PCM WAV, build a chain, tweak the knobs, run it through the C++ effects.

1. Input clip

2. Add effects

3. Chain

Drag a knob up/down to turn it (hold Shift for fine), double-click to reset. Untick a pedal to bypass it.

Axes are linked. Scroll = zoom time, Shift+scroll = zoom amplitude. Drag = box zoom (or pan in Pan mode); a flat box zooms only time, a thin one only amplitude. Double-click = reset view. Click = seek. Drag a level line to move it, double-click it to delete.
